# Failure prediction methodology

No failure-risk model is implemented. Reliable failure dates and exposure history are not available. Future models must specify prediction horizon, target definition, censoring, sampling unit, temporal split, missing-feature behavior, calibration, class imbalance, and uncertainty. Failure probability and consequence must be reported separately. Unknown age/material must remain unknown unless a documented estimate with uncertainty is explicitly produced. Avoid claims of calibrated risk until validation supports them.
